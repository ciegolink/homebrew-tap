# Homebrew tap for Agenoras

[Agenoras](https://github.com/ciegolink/agenoras) – mail, calendar, contacts, tasks and feeds in one app.

```
brew install --cask ciegolink/tap/agenoras
```

Update with `brew upgrade --cask agenoras`, remove with `brew uninstall --cask agenoras`
(add `--zap` to also delete your Agenoras data).
